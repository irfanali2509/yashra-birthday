# Yashra Birthday Website 🌙

This folder is ready for GitHub Pages.

Files:
- index.html
- style.css
- script.js
- assets/ (3 photos + 2 videos)

To publish:
1. Create a public GitHub repository, e.g. `yashra-birthday`.
2. Upload all files and the `assets` folder.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)` → Save.
5. Open the generated `github.io` link.

The website is mobile-friendly and uses the uploaded photos/videos locally, so no external media hosting is needed.
